ENROLLMENT STRENGTH STATEMENT - PWA PACKAGE

IMPORTANT: Install works only from https:// or http://localhost.
It does NOT work if you double-click index.html or open it from inside the zip.
Unzip the folder first.

WINDOWS (no hosting, no Python needed)
1. Unzip the whole folder.
2. Double-click Run-on-Windows.bat. A browser opens at http://localhost:8080/index.html.
   If the window says it is blocked, choose More info > Run anyway.
3. In Edge or Chrome press the "Install App" button (or the install icon at the right of the address bar).
4. After installing, close the black window. The app opens from the Start menu and works offline.
   Open the app online once first so the Excel and PDF libraries are saved.

ANDROID (needs an https link)
1. Unzip on a PC and upload the whole folder to Netlify Drop (app.netlify.com/drop), Cloudflare Pages or GitHub Pages.
2. Open that https link in Chrome on the phone.
3. Press "Install App", or Chrome menu (three dots) > Install app / Add to Home screen.
